# COMP1238 - Data Management Notes

## Week 1 - History
- Writing systems help people record and communicate information.
- Early writing systems helped preserve knowledge.

## Week 2 - Bits and Bytes
- A bit is the smallest unit of digital information.
- One byte consists of eight bits.

## Week 3 - Number Systems
- The binary number system uses 0 and 1.
- The decimal number system uses digits from 0 to 9.

## Week 4 - Text Representation
- Computers represent text using character encoding.
- ASCII and Unicode are examples of character encoding standards.

## Week 5 - Data and Information
- Data consists of raw facts and figures.
- Information is data organized to make it meaningful.
